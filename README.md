YouTuDiak

**YouTuDiak** — это уникальный клон YouTube, скрещенный с личностью Рудяка. Проект полностью воссоздает привычный интерфейс популярного видеохостинга, но адаптирует весь контент, фичи и атмосферу под локальные мемы и контекст Рудяка.

🎯 Основная идея
Создать полноценную альтернативную экосистему YouTube, где контент, авторы, система рекомендаций и взаимодействия пользователей пропитаны «рудяковским» вайбом. 

✨ Ключевые особенности
* **Тематический клон:** Полная визуальная копия интерфейса YouTube (главная страница, поиск, боковая панель, плеер).
* **Специфичный контент:** Лента видео, комментарии и каналы, завязанные на личности Рудяка.
* **Кастомные интеракции:** Фирменная система реакций, комментариев и оценивания роликов.

🛠 Технологический стек
* **Frontend:** JavaScript / TypeScript, React, Tailwind CSS
* **Backend:** Node.js / Express
* **Database:** MongoDB / PostgreSQL
